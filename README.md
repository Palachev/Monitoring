# Monitoring and Logging (DevOps Practice)

Данный репозиторий демонстрирует настройку **мониторинга и логирования инфраструктуры** на Linux-сервере с использованием популярного open-source стека.

Проект выполнен в рамках DevOps-практики и предназначен для изучения и демонстрации подходов к наблюдаемости (observability).

---

## Что реализовано

* **Prometheus**

  * сбор системных метрик с сервера;
  * настройка scrape targets и базовых параметров сбора метрик.

* **Node Exporter**

  * мониторинг CPU, RAM, дисков, сети и состояния системы Linux.

* **Grafana**

  * визуализация метрик Prometheus;
  * создание кастомных дашбордов для контроля состояния сервера и сервисов.

* **Loki**

  * централизованное логирование контейнеров и системных журналов;
  * интеграция логов с Grafana.

* **Docker / Docker Compose**

  * развёртывание monitoring-стека в контейнерах;
  * упрощённый запуск и управление сервисами.

---

## Алерты

Алерты настраивались **непосредственно на сервере** (через Grafana / Alertmanager) и не зафиксированы в репозитории.

В рамках практики использовались уведомления о проблемах с доступностью и состоянием ресурсов.
Конфигурации алертов не коммитились из-за чувствительных данных (webhook’и, токены).

---

## Назначение проекта

Проект используется для:

* изучения monitoring-стека (Prometheus, Grafana, Loki);
* понимания принципов observability в инфраструктуре;
* демонстрации практических DevOps-навыков.

---

## Используемые технологии

* Grafana

* Docker

---

## Примечание

Проект является учебно-практическим и может быть расширен:

* добавлением конфигурации Alertmanager;
* настройкой retention и advanced алертов;
* интеграцией с production-сценариями.
